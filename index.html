Features

Everything you need in a record calendar

Built as a native Lightning Web Component — no iframes, no external dependencies, no data leaving your org.

Month, Week, Day & Agenda

Four views out of the box. Switch between them instantly with keyboard-accessible tabs.

Any Object, Any Relationship

Works on standard and custom objects. Map any lookup, date, and display field through a point-and-click config modal.

Admin-Friendly Setup

No code required. Admins configure child objects, field mappings, colors, and display names from a guided modal — stored as custom metadata.

Permission-Aware

Respects Salesforce object and field-level security. Only admins with the AnyCal+ permission set can configure calendars.

Inline Record Actions

Click an event to view details, open the record, or edit it — all without leaving the page. Create new records from any date.

Locale-Aware

Respects the user's Salesforce locale for date formatting and week start day. Fully translatable with custom labels.

Setup

Up and running in minutes

Three steps from install to a working calendar on any record page.

Install the package

Install AnyCal+ from the AppExchange. Assign the AnyCal+ Admin permission set to your calendar administrators.

Add the component

Open any record page in Lightning App Builder and drag the AnyCal+ component onto the layout.

Configure & go

Click Configure Calendar to map child objects, date fields, and display names. Save, and the calendar is live for all users on that page.
