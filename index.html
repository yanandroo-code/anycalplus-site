Features

Everything you need in a record calendar

A native Lightning Web Component — no iframes, no external services, no data leaving your org.

Month, Week, Day & Agenda

Four views out of the box. Switch instantly with keyboard-accessible tabs.

Any object, any relationship

Standard or custom objects. Map any lookup, date and display field from a point-and-click modal.

Admin-friendly setup

Configure child objects, field mappings, colours and labels from a guided modal. Stored as custom metadata.

Permission-aware

Respects object and field-level security. Only users with the AnyCal+ Admin permission set can configure calendars.

Inline record actions

Click an event to view, open or edit it without leaving the page. Create new records from any date.

Locale-aware

Follows each user's Salesforce locale for date formats and week start. Fully translatable with custom labels.

Setup

Up and running in minutes

Three steps from install to a working calendar on any record page.

Install the package

Install AnyCal+ from the AppExchange and assign the AnyCal+ Admin permission set to your calendar administrators.

Add the component

Open any record page in Lightning App Builder and drag AnyCal+ onto the layout.

Configure & go

Click Configure Calendar, map child objects, date fields and display names. Save — the calendar is live for everyone on that page.
